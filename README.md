# GTime Rent

Website penyewaan paket PC gaming beserta monitor dan paket peripheral, dengan layanan antar-jemput GTR untuk wilayah Bandung, Bojongsoang, dan Dayeuhkolot.

- Naufal Dzaki Akhdani Mohy
- Albiyan Dikha Chandra
- Naufal Rakadilah

## Rencana Fitur

- Registrasi, login Admin/Anggota, dan pengelolaan profil sendiri.
- Katalog dan pencarian unit dengan kode unik serta banyak kategori.
- Admin mengelola unit, kategori, dan anggota.
- Anggota memesan maksimal dua unit. Sistem menahan stok saat checkout.
- Admin mengonfirmasi pembayaran manual sebelum kurir mengirim perangkat.
- Masa sewa maksimal lima hari sejak penyewa menerima perangkat.
- Admin mencatat pengembalian saat GTR menerima perangkat. Sistem menghitung denda per unit, dibulatkan ke atas per 24 jam keterlambatan.
- Dashboard admin, riwayat pribadi anggota, dan cetak riwayat oleh admin.

Paket PC + monitor dihitung satu unit. Paket peripheral dihitung satu unit. Fullset menggabungkan keduanya menjadi dua unit.

## Tech Stack

PHP, Laravel, Blade, MySQL.
